Q13 | 1 Mark | MCQ ⚠️ CLEVER

Linear Algebra — Row-Sum Matrix

Problem: Row sums of A ∈ ℝⁿˣⁿ = 1. B = A³-2A²+A. Does Bx=0 have solutions?

Solution:
- Row sums = 1 means A[1,1,...,1]^T = [1,1,...,1]^T, so λ=1 is eigenvalue of A.
- If λ=1 is eigenvalue of A, then B's eigenvalue = 1³-2(1²)+1 = 0
- B has eigenvalue 0 → det(B)=0 → Bx=0 has infinitely many solutions
Answer: (C) infinitely many solutions

Trap: Not connecting "row sum = 1" to "eigenvalue = 1". This is a disguised eigenvalue question.

Q20 | 1 Mark | MCQ ⚠️ MULTI-CONCEPT

Probability — Linear Transform

Problem: X = aZ+b, Z ~ N(0,1). E[X]=1, E[(X-E[X])Z]=-2, Var(X)=4. Find a,b.

Solution:
- E[X] = aE[Z]+b = b = 1 → b = 1
- Var(X) = a²Var(Z) = a² = 4 → a = ±2
- E[(X-E[X])Z] = E[aZZ] = aE[Z²] = a×1 = a = -2 → a = -2
Answer: (A) a=-2, b=1

Trap: Not recognizing that E[(X-E[X])Z] = Cov(X,Z) = a×Var(Z) = a.

Q28 | 1 Mark | MSQ ⚠️ MULTI-SELECT

Linear Algebra — I + xx^T

Problem: A = Iₙ + xx^T where x^Tx = 1. Which are correct?

Solution:
- Eigenvalues of xx^T: one eigenvalue = x^Tx = 1, rest are 0
- Eigenvalues of A = I + xx^T: one eigenvalue = 1+1 = 2, rest are 1+0 = 1
- (A) Rank = n: YES ✓ (all eigenvalues non-zero)
- (B) Invertible: YES ✓ (determinant = 2×1^(n-1) = 2 ≠ 0)
- (C) 0 is eigenvalue: NO ✗
- (D) A^(-1) has negative eigenvalue: NO ✗ (eigenvalues of A^(-1) are 1/2 and 1, all positive)
Answer: (A, B)

Trap: Thinking xx^T adds rank (it doesn't change the rank of I, which is already full rank).

Q42 | 2 Marks | MCQ ⚠️ OVER-SPECIFICATION TRAP

Neural Network Backprop

Problem: u=2, v=3, weights a=1,b=1,c=1,d=-1,e=4,f=-1. ReLU activation. Find ∂y/∂a and ∂y/∂f.

Solution:
Trace the network forward:
- Node 1 input: au + bv = 1(2) + 1(3) = 5. ReLU(5) = 5.
- Node 2 input: cu + dv = 1(2) + (-1)(3) = -1. ReLU(-1) = 0. ← DEAD NEURON!
- Output y = e×ReLU(node1) + f×ReLU(node2) = 4(5) + (-1)(0) = 20.
- ∂y/∂a: Chain rule through node 1: ∂y/∂(node1 output) × ∂(ReLU)/∂(node1 input) × ∂(node1 input)/∂a = e × 1 × u = 4×1×2 = 8
- ∂y/∂f: = ReLU(node2 output) = 0 → ∂y/∂f = 0
Answer: (A) ∂y/∂a = 8, ∂y/∂f = 0

Trap: Computing the full backprop through node 2 without noticing it's dead (ReLU output = 0). Once ReLU kills the neuron, EVERYTHING downstream of it is zero.

Fastest Path: Identify dead neurons FIRST. Node 2 is dead → ∂y/∂f = 0 immediately.

Q53 | 2 Marks | MSQ ⚠️ EXAM SEPARATOR

ML — SVM from Data

Problem: Class-1: (2,0),(0,2),(2,2). Class-2: (0,0). Hard-margin SVM.

Solution:
Plot the points!
- Class 1 forms an "L" shape at top-right. Class 2 is at origin.
- The separating hyperplane: x₁+x₂ = 2 (passes between (0,0) and the nearest class-1 points)
- w = [1,1], b: w^Tx + b = 0 → x₁+x₂+b = 0. For margin: (2,0) gives 2+b = 1 → b=-1. Check (0,0): 0+0-1 = -1 ✓
- w = [1,1], b = -1 (or scaled version w=[4,4], b differs)
- Support vectors: (2,0), (0,2), (0,0) → 3 support vectors
- Margin = 2/‖w‖ = 2/√2 = √2
- Training accuracy: all 4 points correctly classified → 100% (not 98%)
Answer: (B) 3 support vectors, (C) margin = √2

Trap: (A) is incorrect because w=[4,4] with b=1 doesn't satisfy KKT. (D) is wrong — accuracy is 100%, not 98%.

Q59 | 2 Marks | NAT ⚠️ PROOF QUESTION

Calculus — Lipschitz Condition

Problem: |f(x)-f(y)| ≤ (x-y)². Find f(1)-f(0).

Solution:
Partition [0,1] into n equal parts: 0 = x₀ < x₁ < ... < xₙ = 1, each width 1/n.
- |f(1)-f(0)| ≤ Σ|f(xᵢ)-f(xᵢ₋₁)| ≤ Σ(1/n)² = n × (1/n²) = 1/n
- As n→∞, |f(1)-f(0)| ≤ 0 → f(1)-f(0) = 0
Answer: 0

Trap: Directly substituting x=1, y=0 gives |f(1)-f(0)| ≤ 1, which is true but not tight. The subdivision trick gives the tight bound of 0.

Q60 | 2 Marks | NAT

ML — PCA Max Variance

Problem: n observations in ℝ¹⁰⁰, zero-mean. Covariance eigenvalues λᵢ = 100^(2-i). u = max variance direction. Find (1/n)Σ(u^Tx⁽ⁱ⁾)².

Solution:
- Direction of max variance = eigenvector of largest eigenvalue
- Largest eigenvalue = λ₁ = 100^(2-1) = 100¹ = 100
- (1/n)Σ(u^Tx⁽ⁱ⁾)² = variance along u = λ₁ = 100
Answer: 100

Trap: Confusing which eigenvalue is largest. λ₁ = 100^1 = 100, λ₂ = 100^0 = 1, λ₃ = 100^(-1) = 0.01, etc.

Q16 | 1 Mark | MCQ ⚠️ CLASSIC TRAP

Python — Mutable Defaults

Problem:

def append_to_lst(val, lst=[]):
    lst.append(val)
    return lst
print(append_to_lst(1))   # ?
print(append_to_lst(2))   # ?
print(append_to_lst(3, []))  # ?
Solution:
- Call 1: No lst argument → uses default []. Appends 1. Returns [1]. Default is now [1].
- Call 2: No lst argument → uses SAME default [1]. Appends 2. Returns [1,2].
- Call 3: Explicit [] passed → new list. Appends 3. Returns [3].
- Output: [1], [1,2], [3]
Answer: (B) [1], [1,2], [3]

Trap: Thinking the default [] resets each call. In Python, default mutable arguments are evaluated ONCE at function definition time and persist across calls.

Q21 | 1 Mark | MCQ ⚠️ CLEVER

Linear Algebra — Rotation Powers

Problem: M = rotation matrix with θ = 2π/5. Find M^2026.

Solution:
- M^5 = rotation by 5×(2π/5) = 2π = I (full rotation)
- 2026 = 5×405 + 1 → M^2026 = (M^5)^405 × M¹ = I^405 × M = M
Answer: (B) M

Trap: Trying to compute M^2026 by repeated multiplication. Recognizing the periodicity (M^5=I) instantly reduces this to M^(2026 mod 5) = M^1 = M.

Q34 | 1 Mark | NAT

Probability — Memoryless Property

Problem: X ~ Exponential. P(X>5) = 0.35. Find P(X>10|X>5).

Solution: By memoryless property: P(X > s+t | X > s) = P(X > t). So P(X>10|X>5) = P(X>5) = 0.35
Answer: 0.35

Trap: Computing P(X>10)/P(X>5) from scratch. While correct, the memoryless property gives the answer instantly.

Q52 | 2 Marks | MSQ ⚠️ NOTATION PANIC

Linear Algebra — Centering Matrix

Problem: M = Iₙ - (1/n)11^T. Which are correct? (A) M^T=M (B) M²=I (C) Trace(M)=n (D) M is projection

Solution:
Recognize: M = I - (1/n)11^T is the centering matrix (subtracts the mean).
- (A) M^T = (I - (1/n)11^T)^T = I - (1/n)11^T = M ✓ SYMMETRIC
- (B) M² = M × M. Since M is a projection, M²=M ≠ I ✗
- (C) Trace(M) = Trace(I) - (1/n)Trace(11^T) = n - (1/n)×n = n-1 ≠ n ✗
- (D) M²=M (idempotent) → M is a projection matrix ✓

Verify M²=M: M² = (I-P)(I-P) = I-2P+P² where P=(1/n)11^T. P²=(1/n)²11^T11^T = (1/n)²×n×11^T = (1/n)11^T = P. So M² = I-2P+P = I-P = M ✓
Answer: (A, D)

Trap: (C) looks obviously true (Trace(I)=n) but forgets to subtract (1/n)×Trace(11^T) = 1. (B) confuses projection (M²=M) with involution (M²=I).

Q55 | 2 Marks | NAT ⚠️ THE DEADLIEST TRAP

ML — Ridge Regression with MAE

Problem: Ridge Regression with MAE loss. w=[-3,4]^T, x=[1,2]^T, y_true = x₁+x₂ = 3. Find total regularized loss.

Solution:
- Predicted: y_pred = w^Tx = (-3)(1) + (4)(2) = -3+8 = 5
- y_true = 1+2 = 3
- MAE loss = |y_true - y_pred| = |3-5| = 2 (NOT (3-5)² = 4!)
- Regularizer = 0.20 × ‖w‖² = 0.20 × ((-3)²+4²) = 0.20 × 25 = 5.00
- Total loss = 2 + 5.00 = 7.00
Answer: 7.00

THE #1 TRAP IN GATE DA 2026. The question says MAE (Mean Absolute Error), NOT MSE. Students reflexively square the error because "Ridge Regression = squared error." But the question EXPLICITLY states MAE. Loss = |error|, not error².

Q57 | 2 Marks | NAT

Probability — Bayes (Medical Testing)

Problem: P(+|D)=0.80, P(-|D)=0.20, P(+|D̄)=0.10, P(-|D̄)=0.90. P(D)=0.30. Find P(D|+).

Solution:
- P(+) = P(+|D)P(D) + P(+|D̄)P(D̄) = 0.80×0.30 + 0.10×0.70 = 0.24+0.07 = 0.31
- P(D|+) = P(+|D)P(D)/P(+) = 0.24/0.31 = 0.77 (rounded to 2 decimal places)
Answer: 0.77

Q65 | 2 Marks | NAT

Linear Algebra — Rayleigh Quotient

Problem: A = I - (1/n)11^T. Find max x^TAx where x^Tx = 1.

Solution:
- max x^TAx / x^Tx = largest eigenvalue of A (Rayleigh quotient)
- A = I - (1/n)11^T is the centering matrix
- Eigenvalues: one eigenvalue = 0 (for x = [1,...,1]^T/√n), rest = 1
- max eigenvalue = 1
Answer: 1

Trap: Not recognizing this as a Rayleigh quotient problem. The constrained optimization max x^TAx s.t. x^Tx=1 = max eigenvalue.
